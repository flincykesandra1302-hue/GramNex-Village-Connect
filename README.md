# GramNex (Village Connect)

An Android application that helps villagers discover and access government schemes, using multilingual support, an AI assistant and OCR-based document scanning.

## Problem
Many people in rural communities don't know which government schemes they qualify for, or find the application process hard to follow.

## Features
- Role-based access for citizens, volunteers and admins
- AI assistant that answers scheme-related questions
- Voice search
- OCR document scanning
- Multilingual support
- Volunteer assistance for citizens who need help
- Admin approval workflow

## Tech Stack
- Language: Java
- IDE: Android Studio
- Backend / Database: SQLite
- AI: Gemini API
- OCR: ML Kit
